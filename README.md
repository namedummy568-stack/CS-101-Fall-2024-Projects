# CS-101 Fall 2024 Projects

## Project Submission Guidelines

1.  **Repository Structure:** Each project should be submitted within its own folder in this repository.
2.  **Branching:** Create a new branch for each project (e.g., `student-name-project1`).
3.  **Code:** Ensure your code is well-commented and follows Python best practices.
4.  **README:** Include a `README.md` file within your project folder detailing how to run your project and any dependencies.
5.  **Deadlines:** Adhere to the project deadlines announced in class.
6.  **Pull Requests:** Submit your project by creating a pull request from your project branch to the `main` branch.
